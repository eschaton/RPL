# RPL

An enhanced implementation of a language inspired by the "Reverse Polish
Lisp" language implemented in the HP-28 and HP-48 calculator series.

For a very simple overview, see [the Wikipedia page on RPL](https://en.wikipedia.org/wiki/RPL_%28programming_language%29).
